## 2. 新增：搜索词 × SKU 相关性分析
用户诉求：「对每个花费超过 100 的词，计算这个词与这个 SKU 的相关性，至少要和标题对比，给出依据」。

新增文件：
- `backend/term_relevance.py` — 打分核心（纯规则、可复现、可解释）
- `analyze_term_relevance.py` — 取数 + 出报告（命令行 `--min-cost`，默认 100）
- `verify_term_relevance.py` — T 段回归 **28 PASS / 0 FAIL**
- 产物：`data/reports/term_relevance.{html,md,json}`

### 打分口径（定了就别随便改）
```
score = 0.60×coverage + 0.25×contig + 0.15×lcs      (0~1)
```
- **coverage**：janome 分词取内容词（KEEP_POS = 名詞/動詞/形容詞/形状詞/未知語/カスタム名詞，
  剔除 非自立/代名詞/数詞 与单字假名），逐词在标题里找：完全等同 =1.0；
  能用连续片段覆盖 =0.85；只覆盖一半以上 =0.85×覆盖率；近似词 =0.5×Dice
- **contig**：查询整串的字符有多少比例能在标题里找到连续片段（greedy 最长匹配）
  —— 替代最初的 Dice 成分，因为**长标题会把 Dice 稀释**，导致「整串就是标题子串」只拿 0.78
- **lcs**：最长公共连续子串 / 查询长度
- 分档：≥0.85 高度相关 / ≥0.60 相关 / ≥0.35 弱相关 / <0.35 不相关

### 踩过的坑
- **janome 会把片假名复合词并成一个词**：`ワイヤーメッシュフェンス` 不拆，
  标题里拆开出现时被判不相关。解法 = `covered_ratio()` greedy 最长匹配拆解。
- **`・`(U+30FB) 落在假名区间 U+3040–U+30FF 内**，`normalize()` 最初没剔掉，
  被 `verify_term_relevance.py` 的 T1.2 抓到。已加 `_KANA_PUNCT` 黑名单（保留「ー」U+30FC）。
- 搜索词记录里**没有 asin 字段**，ASIN 只能从 `campaignName`/`adGroupName` 的 `B0XXXXXXXX` 前缀取
  —— 实测 457/457 全部能取到，68 个 ASIN 在 `online_products` 里都有标题。
- 同一「词 × ASIN」会在多个活动/匹配方式里重复出现，必须**合并累加**后再比阈值，
  否则按单行筛 >100 会漏（41 条 → 合并后 45 条）。

## 3. 新增：图片相似度对比
用户给了两张换挡杆头图（刀型 vs 黑色滚花），要求比较相似度。
- `explore/probe_image_similarity.py` + `data/reports/image_similarity.md`
  + `data/reports/image_similarity_check.png`（原图/掩膜/主体裁剪三联图）
- 结论：**两个不同商品**。整图指标被白底抬高（灰度直方图相关性 0.993、HSV 0.969），
  剥掉白底后主体 HSV 相关性掉到 0.667、SSIM 0.415→0.383、掩膜 IoU 0.416。
- **决定性指标是 ORB**：1500 对候选里只有 5 对通过 Lowe 比值检验，RANSAC 拟合不出几何变换
  → 教科书式的「不同物体」。以后判断「是不是同一个商品」优先看 ORB，别只看直方图。
- 环境：pillow 9.5.0 / numpy 2.4.6 / cv2 4.11.0 都可用；Chrome 在
  `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`，可用 `--headless=new --screenshot` 出图自查排版。
