# 08 写 · 产品与否定

> 加产品属 **L2**，否定词也属 **L2**：可归档回滚，但会改变流量结构，需报告。

---

## 加产品

```
POST https://www.sellfox.com/api/cpcSPManage/product/v2/add.json
Content-Type: application/json
```

```json
{
  "shopId": "711811",
  "groupIds": ["445880107588200"],
  "products": [{
    "id": 57615613,
    "shopId": 711811,
    "sku": "abc033-e-a",
    "asin": "B0HJCCY8MS",
    "onlineStatus": "Active",
    "title": "…",
    "imgUrl": "https://m.media-amazon.com/images/I/..._SL75_.jpg",
    "domain": "www.amazon.co.jp",
    "isMeetConditions": true,
    "price": "0",
    "type": "sp",
    "isAdd": false, "variantAdd": false
  }]
}
```

- `groupIds` 可一次传多个（同一产品加到多个组）
- `products[].id` 是**产品库 id**（8 位，从 `product/pageList` 的 `data.rows[].id` 取）

### ⚠️ 部分失败的判定

**HTTP 200 + 根 `code:0` 也可能是失败**。错误藏在 `data` 里，而且是**字符串化的 JSON 数组**：

```json
{"code": 0, "msg": "", "data": "[{\"asin\":\"B0HHWBRQNC\",\"msku\":\"abc005-A-10個セット\",
  \"adGroupName\":\"GR_test2\",\"error\":\"目标广告组 GR_test2 中已有该MSKU，无法添加\"}]"}
```

→ **必须解析 `data`，为空/null 才算全部成功。**

### 同 SKU 重复判定（实测）

| 组内已有状态 | 再次添加 |
|---|---|
| `enabled` | 拒绝（已有该 MSKU） |
| `paused` | **拒绝** |
| `archived` | **允许**，会新增一条 `enabled`（同 SKU 出现两条） |

添加后新广告产品 id 要重新查列表获得。

## 广告产品 暂停 / 归档

```
# 暂停/启用（form）
POST https://www.sellfox.com/api/cpcSPManage/product/updateState.json
shopId=711811&id=79498216492&state=paused

# 归档（form）
POST https://www.sellfox.com/api/cpcSPManage/product/archive.json
shopId=711811&id=79498216492
```

> `id` 是**广告产品 id（组内实例）**，不是产品库 id。
> **同一 SKU 在不同组是两个不同 id**，暂停必须用"该组的"那个。

## 否定关键词

```
POST gw:negative/createSpGroupNeKeywords
Content-Type: application/json
```

```json
{"shopId": "711811", "groupId": "519453497930516",
 "neKeywords": [{"keywordText": "チェストリグ", "keywordTextCn": "战术胸挂",
                 "matchType": "negativeExact"}]}
```

- `groupId` = **Amazon adGroupId**
- `matchType`：`negativeExact`（否定精准）/ `negativePhrase`（否定词组）

### ⚠️ 三个约束

1. **部分失败**：`errMsgList` 非空表示有失败项，`code:0` 不代表全成功。
2. **字符限制**：含下划线的词 Amazon 会报「关键词无效」（`zzz_negtest_01` 三个全失败）。
   提交前过滤 `_`、`|` 等符号。否定词只允许字母/数字/空格/部分标点。
3. **必须先过相关性判定**（见 [05](05-读-商品与竞品.md#词--sku-相关性自家模块非接口)）。

### 什么词才该否（硬门槛）

```
点击 ≥ 10  AND  相关性 < 0.35
```

**只看"0 单"就否词是错的。** 实测 2026-11-08 全部 21 条搜索词都是相关词，
其中 `チェストリグ` 就是「战术胸挂」的日文同义词 —— 否掉等于砍掉最精准的流量。

"相关词不转化"说明问题在价格/图片/评论/配送，不在词。

## 否定商品

### 第一步：校验 ASIN 存在（老路径，非 gw）

```
POST https://www.sellfox.com/api/cpcSPManage/product/searchAsinsForTargeting.json
{"shopId": "711811", "asins": "B0HHHPQQC4"}
→ data: [{asin, sku, title, imgUrl, ...}]    // 不存在返回 []
```

> ⚠️ **一次只能查一个 ASIN**（拼 `"A"+"B"` 会返回 `[]`）。多个 ASIN 要逐个查完再合并提交。

### 第二步：提交

```
POST gw:spTarget/createNeTargeting
{"shopId": "711811", "groupId": "519453497930516",
 "neTargetings": [{"asin": "B0HHHPQQC4", "imgUrl": "...", "isAdd": true, "type": "asin"}]}
```

## 归档否定项（取消否词）

```
POST gw:multiple/neTarget/updateBatchMultiShop
Content-Type: application/json

{"vos": [{"shopId": 711811, "adType": "sp", "neLevel": "group",
          "neType": "keyword",              // 否定商品用 "target"
          "neTargetId": "23223797985689",   // Amazon id
          "id": "39770066465"}]}            // 赛狐内部 id
→ {"code":0,"data":{"successNum":1,"failNum":0,"countNum":1,"errorList":[]}}
```

> **两个 id 都必须传**（和投放层一样的双 id 体系），`neType` 决定操作对象。
> 归档后列表 `state=archived`，`totalSize` 不变（列表含已归档）。

## 能力边界

| 功能 | 否定关键词 | 否定商品 |
|---|---|---|
| 添加 | ✅ `createSpGroupNeKeywords` | ✅ `createNeTargeting` |
| 归档 | ✅ `updateBatchMultiShop` | ✅ 同左 |
| **暂停/启用** | ❌ **无**（Amazon 否定词没有状态） | ❌ 无 |

> 想"临时停用某个否词"只能归档，要用时再加回来。

## UI 坑（做自动化时）

- 否定弹窗底部按钮可能被视口截断（800 高下「添加」在 y=838 不可点）→ 先 `Emulation.setDeviceMetricsOverride` 调高视口
- 行级「归档」与工具栏「归档」同名，按 y 坐标区分
