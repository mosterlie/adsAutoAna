## 文档自身的矛盾

编译时发现 2 处，执行前需实测裁决。

### ① `spGroupInfo.products[].id` 到底是哪个 id

| 出处 | 说法 |
|---|---|
| 原文 §2.1 | 「赛狐**广告产品行 id**，不是 ASIN、也不是 `adId`」 |
| 原文 §11.3 | 「赛狐**广告产品行 id**（非 ASIN）」 |
| 原文 §13.1 | 「**产品库 id**（不是广告产品 id）」 |

**证据**：
- create 样例里是 `56628535`（8 位）
- §13.1 的 `60427897`（8 位，产品库 id）
- 而广告产品 id 是 **11 位**（如 `86988578432`）

**结论**：应该用**产品库 id**。§2.1 与 §11.3 的字段说明有误。
**行动**：第一次建活动时用一个真实产品验证一次，确认后回写本页。

### ② 自动广告的实际出价在哪一层

- 有的章节暗示改「广告组默认竞价」就等于调价
- 但实测有 3 个活动 **组默认竞价 ≠ 匹配位实际出价**

**结论**：实际出价是 4 个匹配位各自的 `bid`。调价请用 `spTarget/updateBid`。

| 现象 | 原因 | 解法 |
|---|---|---|
| `对象不存在` / `code=-1` | 写操作用了 Amazon id | 换成内部 id（列表行里的 `id`） |

| 暂停错组 | 组 id 用了 Amazon adGroupId | `group/update.json` 要 `dxmGroupId` |

## 数据与字段

| 现象 | 原因 | 解法 |
|---|---|---|
| 拿到 `None` 而不是列表 | 在线产品是 `data.rows`，不是 `data.page.rows` | 两种结构都兼容 |
| 活动名取不到 | 字段是 `name`，不是 `campaignName` | `campaignName` 只在搜索词/产品行 |
| ACOS 看着像 31% 其实是 0.31% | `acos` 是百分数值 | `0.31` = 0.31% |
| 日志分页取不到 | `data` 直挂分页，不是 `data.page` | 特殊处理 |
| 分时接口返回全店数据 | `campaign/getAllCampaignHourData` 只认单值 `campaignId` | 别传 list |
| 投放查询 0 行 | `targetType` 默认是 `keyword` | 显式传 `"auto"` |
| 投放查询传 `groupIdList` 返空 | 该接口不认 | 按活动取再用 `adGroupId` 本地过滤 |
| 价格比价结论错 | `online_products` 快照过期 | 比价前刷新售价 |

## 金额与数值

| 现象 | 原因 | 解法 |
|---|---|---|
| 批量调价 14.80 变成 15.00 | JPY 整数币种，批量接口取整 | 精确到小数用单条 `updateBid` |

| `dailyBudget` 报错 | 该字段是字符串 | 传 `"300"` |

## 写操作语义

| 现象 | 原因 | 解法 |
|---|---|---|
| 改预算后其他字段被清空 | `spCampaign/update` 是**全量覆盖** | 先 `adCampaign/getInfo` 读全量再改 |
| 改组名后组名变空 | `group/update.json` 漏了原 `name` | 必须带原组名 |
| 重复建出两个活动 | `ad/sp/create` **非幂等** | 重试前按 `name` 查重 |
| 加组时否定词被写重 | 追加组时带了 `neKeywords` | 加组时清空否定项 |
| 想把活动移出组合失败 | 亚马逊不支持"无组合" | 只能移入另一个组合 |
| 找不到"暂停否定词" | Amazon 否定词没有状态 | 只能归档 |

## 抓包与自动化（做逆向时会遇到）

| 现象 | 原因 | 解法 |
|---|---|---|
| 读 `document.body` 只有菜单 | 内容在 `wujie-app` 的 **shadow DOM** | 穿透 `shadowRoot.querySelector('body').innerText` |
| `page.on("request")` 抓不到关键词请求 | 页面注册了 service worker | 用浏览器级 CDP `Target.setAutoAttach` 附加所有 target |
| 按钮点了没反应 | 需要真实鼠标事件 | `Input.dispatchMouseEvent` 三连（moved/pressed/released） |
| `btn.click()` 在商品投放模式不触发 | 两种模式行为不一致 | 一律用真实鼠标 |
| `elementFromPoint` 只返回宿主元素 | 在 shadow 里 | 用 `shadowRoot.elementFromPoint(x,y)` |
| 抓不到创建请求体 | 提交后页面立即跳转 | click 后立刻读 response body |
| 「添加」按钮选择器取不到 | 实际是 `<span>` 不是 `button` | 用坐标点击 |
| 广告位「调整」下拉打不开 | CDP 限制 | 菜单项从隐藏 DOM 读，或直接调接口 |
