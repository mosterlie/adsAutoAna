## 创建活动

```
POST gw:ad/sp/create
Content-Type: application/json
```

### 请求体三段

```json
{
  "shopId": "711811",
  "marketplaceId": "A1VC38T7YXB528",
  "spCampaignInfo": {
    "campaignId": "", "startDateStr": "2026-11-10", "endDateStr": "2026-12-10",
    "dailyBudget": "300", "targetingType": "manual", "strategy": "autoForSales",
    "placementTop": null, "placementRestOfSearch": null,
    "placementProductPage": null, "placementSiteAmazonBusiness": null,
    "creativeBidPercentage": null, "campaignSite": "amazonAll",
    "name": "CA_xxx", "portfolioId": "",
    "audienceId": "", "audienceBidPercentage": "", "defaultAudience": false
  },
  "spGroupInfo": {
    "groupId": "", "defaultBid": "20", "name": "GR_xxx",
    "products": [{"id": 57615613, "sku": "abc033-e-a", "asin": "B0HJCCY8MS",
                  "mainImage": "https://...jpg", "spotlightVideos": null}]
  },
  "spTargetInfo": {
    "autoTarget": false, "keywordTarget": true,
    "keywords": [{"keywordText": "排水溝", "matchType": "exact", "bid": "25"}],
    "targetings": [],
    "neKeywords": [], "neTargetings": []
  }
}
```

### 自动 vs 手动 vs 商品投放

| 模式 | 怎么表达 |
|---|---|
| 自动投放 | `autoTarget: true`、`keywordTarget: false`、`targetings: []`；4 档竞价用 `queryHighRelMatchesBid` 等字段 |
| 手动关键词 | `autoTarget: false`、`keywordTarget: true`、`keywords[]` 非空 |
| 手动商品投放 | `autoTarget: false`、`keywordTarget: false`、`targetings: [{type:"asin", asin, bid}]` |

### 字段类型（与 update 接口不同，容易写错）

| 字段 | create | update |
|---|---|---|
| 广告位加价 | **字符串** `"15"` | **数字** `15` |
| `dailyBudget` | 字符串 `"300"` | 字符串 `"300"` |
| `campaignId` 标识 | `""` 表示新建 | `dxmCampaignId`（数字） |
| 结构 | 三段嵌套 | 单层扁平 |
| `portfolioId` | 组合 id 或 `""` | 无组合传 `"-1"` |

### 响应判读

```json
{"code": 0, "data": {
  "campaignResp": {"code": 0, "campaignId": "262736104900156"},
  "groupResp":    {"code": 0, "adGroupId": "365363228240902"},
  "targetResp":   {"code": 0, "targetType": "autoTarget",
                   "targetList": [{"code": 0, "targetId": "...", "matchTypeForAutoTarget": "queryHighRelMatches"}]},
  "neKeywordResp": {"code": 0}, "neTargetResp": {"code": 0}}}
```

**根 `code=0` 不等于成功**，要逐个看子 `Resp.code`。

### 三个必须注意的点

1. **非幂等**：每次调用都新建。重试前必须按 `name` 查重（赛狐禁止活动重名）。
2. **`products[].id` 用产品库 id（8 位）**。文档 §2.1 说是"广告产品行 id"、§11.3 也这么写，
   但 §13.1 说是"产品库 id"，且所有样例里都是 8 位数字（`56628535`、`60427897`），
   而广告产品 id 是 11 位。→ **按产品库 id 走，首次执行时验一次**。详见 [11 踩坑总表](11-踩坑总表.md#文档自身的矛盾)。
3. **`targetings[]` 字段未经完整实测**（抓包时请求体未保存），`type`/`asin`/`bid`/`isAdd`
   来自前端源码推断。第一次跑商品投放时先只建一个，看响应再批量。

## 修改活动

```
POST gw:spCampaign/update
Content-Type: application/json
```

```json
{"shopId": "711811", "dxmCampaignId": 13804946433, "name": "CA_xxx",
 "portfolioId": "-1", "startDateStr": "2026-11-10", "endDateStr": "2026-12-10",
 "dailyBudget": "150", "targetingType": "auto", "strategy": "manual",
 "placementTop": 15, "placementProductPage": 35, "placementRestOfSearch": 25,
 "placementSiteAmazonBusiness": 45, "creativeBidPercentage": 0,
 "audienceId": "", "audienceBidPercentage": 0, "defaultAudience": false,
 "campaignSite": "amazonAll", "offAmazonBudgetControlStrategy": null}
```

> ⚠️ **全量覆盖语义**：请求体没带的字段可能被清空。
> **改预算/策略前必须先 `adCampaign/getInfo` 读一次原值，只改目标字段再整体提交。**

只改活动层（名称/组合/日期/预算/策略/广告位/受众）；改组/投放要走各自接口。
接口不回传新值，需再查列表确认。

## 暂停启用

```
POST gw:spCampaign/updateState
Content-Type: application/x-www-form-urlencoded        ← 必须 form

shopId=711811&id=13804946433&state=paused
```

- `id` = **`dxmCampaignId`**（内部数字，不是 Amazon campaignId）
- `state` = `paused` / `enabled`
- 用 JSON 提交会报 `360000 请求参数错误`

### 状态对照

| `state` | `servingStatus` | 含义 |
|---|---|---|
| `enabled` | `PENDING_START_DATE` | 已开启但未到开始日期 |
| `enabled` | `CAMPAIGN_STATUS_ENABLED` | 正常投放（列表显示"正在投放"） |
| `paused` | `CAMPAIGN_PAUSED` | 已暂停 |
| `archived` | — | 已归档 |

## 归档

```
POST gw:spCampaign/archive
Content-Type: application/x-www-form-urlencoded

shopId=711811&id=13804946433
```

> **不可逆**。归档后默认视图不再展示，需 `statusList: ["archived"]` 才能查到。
> 想恢复只能重建一个活动。

## 给已有活动加组

**复用 `ad/sp/create`**，靠 `spCampaignInfo.campaignId` 非空来区分。

| 字段 | 新建活动 | 加组 |
|---|---|---|
| `spCampaignInfo.campaignId` | `""` | **已有活动 id** |
| `spCampaignInfo.name` | 新活动名 | `""`（不动） |
| 日期 | 实际日期 | `""`（不动） |
| `dailyBudget` | 预算 | 活动当前预算（仅透传） |
| 4 个广告位 | 数字 | **`null`** |
| `portfolioId` | 组合 id | `""` |
| `neKeywords` / `neTargetings` | 可空 | **清空**，否则会把已有否定项重复写一遍 |

响应里 `campaignResp.campaignId` 回的是**原活动 id**，新组 id 在 `groupResp.adGroupId`。

## 1 个活动 + N 个广告组

> `spGroupInfo` 是**对象不是数组**，一次请求只能建 1 个组。N 个组 = N 次调用。

```
① 建活动 + 第 1 组：campaignId=""，spGroupInfo 填 G1
       ↓ 拿到 campaignId
② 追加第 2 组：campaignId=<上一步>，spGroupInfo 填 G2
       ↓
③ … 重复
       ↓
④ 读回校验：multiple/group/getAllGroupData[campaignIdList=[活动ID]]
```

```python
cid = ""
for g in groups:
    payload = build(campaign_id=cid, group=g)       # 首次 cid 为空
    d = post("ad/sp/create", payload)["data"]
    cid = cid or d["campaignResp"]["campaignId"]    # 首次回填
    g["adGroupId"] = d["groupResp"]["adGroupId"]
    time.sleep(2)
```

**耗时参考**

| 组数 | 调用次数 | 预计耗时 |
|---|---|---|
| 1 | 1 | 2–3s |
| 3 | 3 | 7–9s |
| 10 | 10 | 25–30s |
| 30 | 30 | 80–95s |

**失败处理**：某次追加失败只影响该组，活动已建成功；重试前先按组名查重。
全部失败时可能残留"只有活动没有组"，需人工清理。

**命名**：组名可重复无唯一校验，建议 `G1_<HHMMSS>` 便于回溯。

## 广告组设置

### 读（GET，老路径）

```
GET https://www.sellfox.com/api/cpc/group/getInfo.json
    ?shopId=711811&campaignId=<Amazon id>&groupId=<Amazon adGroupId>&type=sp
```

返回 `{adGroupName, defaultBid, state, groupType, campaignName, ...}`

### 改组名 / 默认竞价（JSON，老路径）

```
POST https://www.sellfox.com/api/cpcSPManage/group/update.json
{"shopId": "711811", "dxmGroupId": 11818153634,
 "name": "GR_排水沟_B0HJCLZPM4", "defaultBid": "26.00"}
```

> ⚠️ **必须带原 `name`**，漏了会被清空。

### 组暂停 / 启用（form）

```
POST https://www.sellfox.com/api/cpcSPManage/group/updateState.json
shopId=711811&id=11818153634&state=paused
```

> ⚠️ **改组默认竞价未必改变实际出价**。自动广告的实际出价看 4 个匹配位各自的 `bid`，
> 很多活动两者并不相等（见 [03 投放](03-读-广告表现.md#投放)）。**要真正调价请用 `spTarget/updateBid`。**
