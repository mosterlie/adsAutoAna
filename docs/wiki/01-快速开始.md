# 01 快速开始

> 一页讲清：怎么鉴权、请求发到哪、用什么编码、id 用哪个。

## 鉴权：只要 Cookie

实测结论：**只带登录 Cookie、不带 `sf-vvv-*` 签名头，写接口同样可以成功**（`ad/sp/create` 实测 2 次均 `code:0`）。

必需请求头：

```
Content-Type: application/json        ← 或 form-urlencoded，看接口
Accept: application/json, text/plain, */*
Origin: https://www.sellfox.com
Referer: https://www.sellfox.com/cpc-vue3/web/cpc-vue3/ads-management?openfrom=clickmenu
User-Agent: <Chrome UA>
X-Language: zh-CN
Cookie: <含 sf_u 的登录态>
```

Cookie 两个来源：

- **CDP 浏览器级** `Storage.getCookies`（不依赖任何页面，最稳）
- 已登录 Chrome 的 `context.cookies()` 过滤 `domain` 含 `sellfox.com`

本项目落在 `data/cookies.json`（`config.COOKIE_PATH`），**不要提交 git**。

登录态失效的表现是 `code=2001`。此时重新从浏览器取，不要高频重登。

## 请求发到哪：三套路径并存

这是最容易浪费时间的地方——**同一个"暂停"，活动和组在不同路径下**。

| 路径族 | 前缀 | 编码 | 典型接口 |
|---|---|---|---|
| **gw 网关** | `/api/gw/sellfox/sellfox-cpc/api/sellfox/` | JSON | 大部分读接口、`ad/sp/create`、`spCampaign/update`、`spTarget/*`、`multiple/*` |
| **老路径（form）** | `/api/cpcSPManage/` 或 `/api/portfolio/` | **form-urlencoded** | `group/update.json`、`group/updateState.json`、`product/updateState.json`、`campaign/updatePlacementAdjustment.json`、`portfolio/*.json` |
| **老路径（GET/JSON）** | `/api/search/...`、`/api/cpc/...` | JSON / GET 参数 | `terms/analysis/getTrend.json`、`group/getInfo.json` |

> ⚠️ **编码错了报 `360000 请求参数错误`**。看到 360000 先怀疑编码和字段类型，不要怀疑权限。

### 大小写坑

`updatePortFolioData` / `removePortFolioData` / `movePortFolioData` 是**大写 P（Folio）**，
而 `getAllPortfolioData` 是小写。写错直接 404 或跳登录页。

## 通用封装

```python
import json, requests

GW     = "https://www.sellfox.com/api/gw/sellfox/sellfox-cpc/api/sellfox/"
ORIGIN = "https://www.sellfox.com"

def _hdr(kind="json"):
    return {
        "Content-Type": "application/json" if kind == "json" else "application/x-www-form-urlencoded",
        "Accept": "application/json, text/plain, */*",
        "Origin": ORIGIN,
        "Referer": f"{ORIGIN}/cpc-vue3/web/cpc-vue3/ads-management?openfrom=clickmenu",
        "User-Agent": "Mozilla/5.0 ... Chrome/134 ...",
        "X-Language": "zh-CN",
        "Cookie": "; ".join(f"{k}={v}" for k, v in json.load(open("data/cookies.json")).items()),
    }

def post(path, body, kind="json", base=GW):
    url = path if path.startswith("http") else (
        ORIGIN + path if path.startswith("/") else base + path)
    fn = requests.post
    r = fn(url, **({"json": body} if kind == "json" else {"data": body}),
           headers=_hdr(kind), timeout=60)
    d = r.json()
    if isinstance(d.get("data"), str):        # 部分接口 data 是字符串化的 JSON
        try:
            d["data"] = json.loads(d["data"])
        except Exception:
            pass
    return d

def rows(d, *keys):
    """兼容 {data:{page:{rows}}} 与 {data:{rows}} 两种结构"""
    data = d.get("data") or {}
    page = data.get("page") if isinstance(data.get("page"), dict) else data
    for k in ("rows",) + keys:
        if isinstance(page.get(k), list):
            return page[k]
    return []
```

> **两种返回结构都要兼容**：广告列表多是 `data.page.rows`，但**在线产品** `product/pageList` 是 `data.rows`（照 `data.page.rows` 写会拿到 None）。

## 双 id 体系（最容易错的地方）

| 层级 | 读 / 查询用 | 写 / 操作用 |
|---|---|---|
| 广告活动 | **Amazon `campaignId`**（15 位） | **`dxmCampaignId`**（内部，11 位） |
| 广告组 | Amazon `adGroupId` | **`dxmGroupId`** |
| 投放 | Amazon `targetId`（建议价用它） | **内部 target id** |
| 广告产品 | —— | 加产品用**产品库 id**（8 位）；改状态用**广告产品 id**（组内实例，11 位） |
| 广告组合 | `portfolioId`（写也用这个，**唯一例外**） | 同左 |

三条具体规则：

1. 内部 id 从列表接口的行里取：活动取 `id`、组取 `id`、投放取 `id`。
2. **同一 SKU 在不同组是两个不同的广告产品 id**，暂停必须用"该组的"。
3. 传错 id 的典型报错是 `对象不存在` 或 `code=-1`。

## 分页与参数

- `pageSize` 上限 **200**（给更大也只返 200）
- 列表接口普遍返回 `data.page.{rows,totalSize,totalPage}`
- `defaultPageType=1` 返回行，`=2` 只返回 `totalSize`
- **过滤参数不可信**：`statusList` / `portfolioIdList` / `adType` 传了也不严格生效 → 拉全量后本地二次过滤

---

## 节制规则（别把账号搞进风控）

| 项 | 建议 |
|---|---|
| 相邻写请求间隔 | ≥ 2s（建活动每次 2–3s） |
| 单次批量 | 控制在几十条内 |
| 重试 | 不做重试风暴；`code != 0` 直接停 |
| Cookie | 失效再取，不要高频重登 |
| 平台限流表现 | `429` 或要求重新登录 |

## 最小可用示例（建活动）

完整请求体见 [`docs/samples/sp_create_request.json`](../samples/sp_create_request.json)。

```python
payload = json.load(open("docs/samples/sp_create_request.json", encoding="utf-8"))
payload["spCampaignInfo"]["campaignId"] = ""          # 空 = 新建活动
payload["spCampaignInfo"]["name"] = "CA_api_test"
d = post("ad/sp/create", payload)
print(d["data"]["campaignResp"]["campaignId"])
```

注意 `code=0` 之后还要看 `campaignResp.code` / `groupResp.code` / `targetResp.code`。
