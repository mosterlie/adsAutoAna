# 09 写 · 组合与策略

> 广告组合（Portfolio）的写接口**不在 gw 前缀下**，走老路径 `/api/portfolio/*.json` + **form 编码**。
> 读接口仍在 `gw:multiple/portfolio/getAllPortfolioData`（JSON）。

---

## 创建组合

```
POST https://www.sellfox.com/api/portfolio/createPortfolioData.json
Content-Type: application/x-www-form-urlencoded

shopId=711811&portfolioName=PF_api_test_1107
→ {"code": 0, "msg": "success", "data": "270905298437020"}
```

- **最小只要两个参数**：`shopId` + `portfolioName`
- 响应 `data` 就是新建的 **portfolioId**

---

## 修改组合

```
POST https://www.sellfox.com/api/portfolio/updatePortFolioData.json
Content-Type: application/x-www-form-urlencoded

portfolioName=PF_api_test_1107_v2
shopId=711811
policy=noBudget
portfolioId=270905298437020
amount=0.00
budgetEndDate=
budgetStartDate=
budgetSharingState=ENABLED
```

> ⚠️ **必须带全，少一个就 `360000 请求参数错误`**。只传 `portfolioId` + `portfolioName` 会失败。

| 字段 | 含义 |
|---|---|
| `policy` | 预算策略（`noBudget` = 不启用预算管理） |
| `amount` / `budgetStartDate` / `budgetEndDate` / `budgetSharingState` | 未启用时传 `0.00` / 空串 / `ENABLED` |

> ⚠️ 路径里是**大写 P（`updatePortFolioData`）**，而读接口是 `getAllPortfolioData`（小写）。

## 活动移入组合

```
POST https://www.sellfox.com/api/portfolio/movePortFolioData.json
Content-Type: application/x-www-form-urlencoded

shopId=711811&portfolioId=29811114365267&campaignIds=90709676806138
```

- `campaignIds` 是**亚马逊 campaignId**，逗号分隔可多个
- 批量时 `data` 返回 `[{campaignId, name, errMsg}]` 逐条结果，**部分失败不报错**，要看 `errMsg`

### ⚠️ 不能移出组合

`portfolioId=0` 想移出 → Amazon 报 `"errMsg": "EntityID does not exist."`。

**亚马逊组合体系没有"无组合"回退**，只能把活动移入**另一个**组合。

> 这是设计上的限制，不是 bug。做"把活动从组合里拿出来"的需求时，只能造一个临时组合接住。

| 方法 | 路径 | 用途 | 状态 |
|---|---|---|---|
| `updatePortfolioHiddenState` | `/api/portfolio/updatePortfolioHiddenState.json` | 隐藏/显示 | 🟡 未逐个实测 |

| `updatePortFolioRank` | `/api/portfolio/updatePortFolioRank.json` | 排序 | 🟡 |

> **删除组合是死路**：新旧两版前端都已无调用点，试了 8 种参数组合全部 `360000`；
> 且亚马逊组合 API 本身不支持删除。真要"删"，用 `updatePortFolioData` 置空预算 +
> 把活动移走 + `updatePortfolioHiddenState` 隐藏。

### 组合的两个 id

| id | 示例 | 用途 |
|---|---|---|
| 亚马逊 `portfolioId` | `270905298437020` | 创建时返回、`move` 用它、列表展示。**写接口也用它（唯一例外）** |
| 赛狐内部 id | `1646953252` | 列表行 `id` 字段，**暂未发现写接口使用** |

## 分时预算模板

> 页面：广告组合 → 广告策略 tab。模板与应用分离：先建模板，再应用到具体组合。

### 建模板

```
POST gw:strategy/insertTemplate
Content-Type: application/json
```

```json
{"shopId": "711811",
 "templateName": "zzz_test_budget_tpl",
 "marketplaceId": "A1VC38T7YXB528",
 "itemType": "PORTFOLIO",
 "type": "DAILY",
 "portfolioRuleList": [{"siteDate": "0", "portfolios": [{"amount": 500}]}],
 "returnValue": {"policy": "noBudget", "amount": ""},
 "effectiveStartTime": "2026-11-08",
 "effectiveEndTime": "2026-12-08"}
→ {"code":0,"msg":"新增模板:933343","data":"933343"}      ← data 即 templateId
```

| 字段 | 说明 |
|---|---|
| `type` | `HOUR` / `DAILY` / `WEEKLY`（设置方式 + 周期） |
| `portfolioRuleList` | DAILY 固定 `siteDate="0"`；HOUR 用 `portfolioHourRuleList` |
| `returnValue.policy` | `noBudget`（无上限）/ `MonthlyRecurring` / `dateRange` |

仅保存 = 只调 `insertTemplate`。

### 保存并应用

```
POST gw:strategy/schedule/submitStrategy
{"templateId": "933343", "itemType": "PORTFOLIO",
 "adStrategyStatusVoList": [{"policy": "noBudget", "itemId": "<组合 portfolioId>",
                             "shopId": "711811", "marketplaceId": "A1VC38T7YXB528"}]}
```

### 读 / 删

```
POST gw:strategy/getPageTemplate
{"shopId":"711811","itemType":"PORTFOLIO","pageNo":1,"pageSize":20}
→ rows[{id, templateName, type, effectiveStartTime/EndTime, effectiveStatus, usageAmount}]

POST gw:strategy/deleteTemplate
{"templateId": "933343"}
```

> 免费套餐只允许 1 条策略模板，超出报 `360000` 相关错误。

### 相关接口全景（同一策略体系）

| 类别 | 路径（`gw:` 前缀） |
|---|---|
| 模板 | `strategy/insertTemplate` `updateTemplate` `deleteTemplate` `getPageTemplate` `updateTemplateStatus` |
| 应用/撤除 | `strategy/schedule/submitStrategy` `updateStrategy` `removeStrategy` `transferStrategy` |
| 独立页 | `strategy/schedule/independentPageQuery` `independentCampaign` `independentTarget` |
| 预览 | `strategy/schedule/executePreview` `queryCampaignPreview` |
| 受控对象 | `strategy/schedule/pagePortfolioList` `pageCampaignList` `pageAdGroupList` `pageTargetList` |
| 任务 | `strategy/task/pageTaskRecord` `processTask` |
| Tab 状态 | `strategy/tabStatus` |

### UI 坑

- 该页弹窗的保存/取消在 CDP 下**均无法触发**（DOM click、真实鼠标、强制显隐都无效）——但接口可直接调用
- 校验：名称 + 生效日期必填；HOUR 模式还需至少一个时段有预算值（空时静默 return，无提示）
- 时间格是拖拽绘制组件（`scheduleColumn` + `data-coordinate`），非标准输入框
