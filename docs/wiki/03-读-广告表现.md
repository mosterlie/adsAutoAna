# 03 读 · 广告表现

> 覆盖：活动 / 组 / 投放 / 产品 / 广告位 / 分时 / 建议价 / 日志 / 否定。
> 所有接口都在 gw 前缀下，**JSON 编码**，只需 Cookie。

---

## 活动列表

`POST gw:campaign/getAllCampaignData`

```json
{
  "shopIdList": ["711811"], "adType": "sp",
  "statusList": ["enabled", "paused"],
  "startDate": "2026-11-08", "endDate": "2026-11-08",
  "orderField": "adCost", "orderType": "desc",
  "pageNo": 1, "pageSize": 200, "fromSingle": true
}
```

- **日级取数**：`startDate = endDate = 当天`；给区间 = 区间累计
- **逐日曲线**：按天循环，一天一次调用
- 按名字搜：加 `"searchType": "contains", "searchField": "name", "searchValue": "B0HLKZD3MZ"`

**行内字段**

| 类别 | 字段 |
|---|---|
| 标识 | `campaignId`（Amazon）、`id`（内部 dxmCampaignId）、`name` |
| 状态 | `state`、`servingStatusName`、`campaignTargetingType` |
| 配置 | `dailyBudget`、`strategy`、`portfolioName`、`portfolioId` |
| 指标 | `impressions` `clicks` `ctr` `cvr` `adCost` `adCostPerClick` `adOrderNum` `adSale` `acos` `roas` `cpa` `addToCart` `detailPageViews` |

> ⚠️ **字段名是 `name`，不是 `campaignName`**。`campaignName` 只出现在搜索词/产品行里。

> ⚠️ `statusList` / `portfolioIdList` / `adType` **都不严格生效**，返回可能是全量。按行字段本地过滤。

> ⚠️ `acos` 是百分数值：`0.31` 表示 **0.31%**，不是 31%。

## 广告组

`POST gw:multiple/group/getAllGroupData`

```json
{"shopIdList": ["711811"], "campaignIdList": ["90709676806138"], "adType": "sp",
 "startDate": "2026-11-08", "endDate": "2026-11-08"}
```

返回行：`id`（内部 `dxmGroupId`）、`adGroupId`（Amazon）、`name`、`state`、`defaultBid`。

### 三个 id 别混

| id | 示例 | 用途 |
|---|---|---|
| 内部 `dxmGroupId` | `11818153634` | 改组名/默认价/状态 |
| Amazon `adGroupId` | `445880107588200` | `group/getInfo.json`、各组列表接口的 `adGroupIds` |
| URL 里的上下文 id | `86986007429` | **接口不用**，仅页面跳转 |

## 投放

`POST gw:multiple/target/getAllTargetData`

```json
{"orderField": "adCost", "orderType": "desc", "shopIdList": ["711811"],
 "campaignIdList": ["90709676806138"], "adType": "sp",
 "targetType": "auto", "matchTypes": [], "statusList": ["enabled", "paused"],
 "startDate": "2026-11-08", "endDate": "2026-11-08",
 "pageNo": 1, "pageSize": 200, "fromSingle": true, "useAdvanced": false}
```

**三个必踩的点**

1. `campaignIdList` 要传 **Amazon campaignId（15 位）**，传内部 id（11 位）会 0 命中。
2. `targetType` 默认是 `keyword`，**查自动投放必须显式传 `"auto"`**。
3. `targetType` 合法值只有 `auto` / `keyword` / `targeting`，其他报参数错误。

**自动投放固定 4 行**（Auto Targeting 四档）：

| 匹配位 | 含义 |
|---|---|
| `queryHighRelMatches` | 紧密匹配 |
| `queryBroadRelMatches` | 宽泛匹配 |
| `asinSubstituteRelated` | 同类商品 |
| `asinAccessoryRelated` | 关联商品 |

> ⚠️ **很多活动这 4 行的 bid ≠ 组默认竞价**（实测匹克球网默认 13、实际 20；战术胸挂默认 25、实际 30）。
> **实际出价看这 4 行的 `bid`，不是组默认竞价。**

## 广告产品

`POST gw:multiple/adProduct/getAdProductList`

```json
{"type": "sp", "campaignIdList": ["90709676806138"], "shopIdList": ["711811"],
 "statusList": ["enabled", "paused"], "startDate": "2026-11-08", "endDate": "2026-11-08",
 "pageNo": 1, "pageSize": 200, "orderBy": "adCost", "desc": true,
 "searchContents": [], "searchMode": "exact", "searchType": "asin",
 "adStrategyTypeList": [], "servingStatusList": [], "useAdvanced": false}
```

> ⚠️ 字段是 **`type`**，不是 `adType`。

行里 `id` 是**广告产品 id（组内实例）**，不是产品库 id，也不是 ASIN。

## 广告位

`POST gw:multiple/placement/getAllPlacementData`

```json
{"dxmCampaignId": "", "campaignSite": "", "orderField": "adCost", "orderType": "desc",
 "adType": "sp", "campaignIdList": ["90709676806138"], "devIds": [],
 "strategyType": "", "predicate": "", "startDate": "2026-11-08", "endDate": "2026-11-08",
 "isCompare": false, "compareStartDate": "", "compareEndDate": "",
 "adStrategyTypeList": [], "pageNo": 1, "pageSize": 20, "fromSingle": true}
```

返回**固定 4 行**（同一活动的 4 个广告位），用 `predicate` 区分，`id` 都是**活动内部 id**：

| predicate | 广告位 | 可调 |
|---|---|---|
| `placementTop` | 搜索结果顶部 | ✅ |
| `placementRestOfSearch` | 搜索结果其余 | ✅ |
| `placementProductPage` | 商品详情页 | ✅ |
| `offAmazon` | 站外 | ❌ `isUpdateBid=false` |

每行 `percentage` = 该位当前加价比例。没有独立的"广告位 id"。

## 分时

`POST gw:multiple/target/getAllTargetHourData`

| `dateModel` | 维度 | 返回形态 |
|---|---|---|
| `HOURLY` | 活动/组/投放（由出入参决定） | `hour[]`，每指标一条、records 为 24 值 |
| `HOURLY_ASIN` | 广告产品 | `periodReportList` 每产品一行 + `detail[24]` |
| `HOURLY_KEYWORD` | 投放/匹配 | 每投放一行 + `detail[24]` |
| `HOURLY_PLACEMENT` | 广告位 | 每广告位一行 + `detail[24]` |
| `DAILY` | 当天汇总 | `hour` 只有 1 条 |

另外三个（`HOURLY_TARGET` / `HOURLY_SEARCH_TERM` / `HOURLY_CAMPAIGN`）报 `160000 系统异常`。

### 分时接口的"单值 vs 列表"陷阱

| 接口 | 认什么 |
|---|---|
| `campaign/getAllCampaignHourData` | **只认单值 `campaignId`**，传 `campaignIdList` 退化成全店 |
| `multiple/group/getAllGroupHourData` | 反之，认 `groupIdList` |

## 建议竞价

```json
// 投放维度（自动匹配位 / ASIN 定向 / 品类定向）
POST gw:spTarget/getSuggestedBid
{"shopId": "711811", "targetIds": "14313810921,14313810920"}

// 关键词维度
POST gw:spKeyword/getSuggestedBid
{"shopId": "711811", "keywordIds": "90429492515259"}
```

返回 `suggested` + `rangeStart` / `rangeEnd`；自动位另有 `estimatedImpressionLower/Upper`。

> ⚠️ `targetIds` 必须是**逗号字符串**（传数组报 160000）；必须是 **Amazon targetId**（传内部 id 报"对象不存在"）。

`extension[0].type` 可反查投放位类型：`queryHighRelMatches` / `queryBroadRelMatches` / `asinSubstituteRelated` / `asinAccessoryRelated`。

## 操作日志

`POST gw:log/sellfoxAndAuto/getPage`

```json
{"types": ["sp"], "shopIdList": ["711811"],
 "startDate": "2026-11-01", "endDate": "2026-11-08", "pageNo": 1, "pageSize": 200}
```

> ⚠️ `data` **直挂分页对象**，不是 `data.page`。

字段：`action`（`editBudget` `editBid` `editState` `editPortfolio` `add` `editName` `editBidStrategy` `editDate`）、
`logType`（`sellfox` / `scheduler`）、`operationTime`（服务器 UTC+8）、`siteOperationTime`（站点时区，JP 为 UTC+9，比服务器晚 1 小时）。

> **只记录赛狐侧操作**。在亚马逊后台改的预算这里查不到。

## 否定投放（读）

`POST gw:multiple/neTarget/getAllNeTargetData`

```json
{"orderField": "adCost", "orderType": "desc", "shopIdList": ["711811"],
 "campaignIdList": ["90709676806138"], "groupIdList": ["445880107588200"],
 "adType": "sp", "neType": "keyword", "neLevels": ["group"], "matchType": "",
 "servingStatusList": [], "startDate": null, "endDate": null, "neBeforeAfterDay": 30,
 "dataFrom": 2, "searchType": "exact", "searchField": "name", "searchValue": "",
 "devIds": [], "useAdvanced": false, "pageNo": 1, "pageSize": 50, "onlyShowImpressions": false}
```

`neType` 只有 `keyword` / `target`（否定商品用 `target`，不是 `product`）。

写操作见 [08 写·产品与否定](08-写-产品与否定.md)。
