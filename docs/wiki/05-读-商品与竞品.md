## 我方产品与售价

```
POST https://www.sellfox.com/api/gw/sellfox/sellfox-product/sellfox/product/pageList
Content-Type: application/x-www-form-urlencoded      ← 必须 form，不是 JSON
```

参数必须带全（缺项可能返回空）：

```python
BASE = {
    "currency": "", "pageType": "child", "asinType": "asin", "shopIds": "711811",
    "marketplaceId": "", "labelIds": "", "labelQuery": "0",
    "onlineStatus": "active,inActive", "switchFulfillmentTo": "", "isVariation": "",
    "match": "", "lowCostStore": "", "searchField": "asin", "searchValue": "",
    "searchMode": "exact", "pageSize": "200", "pageNo": "1", "fullCid": "",
    "organiser": "", "startTime": "", "endTime": "", "buyBoxWinners": "",
    "defaultFilterType": "1", "productBundle": "", "useAdvanced": "1", "devIds": "",
    "advancedSearchItem": "", "defaultPageType": "1", "complianceStatus": "",
}
```

查询时把 `searchValue` 设成 ASIN、`searchMode` 设 `exact`。

### 返回结构（易踩）

```python
rows = (d.get("data") or {}).get("rows") or []      # ✅ 正确
rows = (d.get("data") or {}).get("page", {}).get("rows")   # ❌ 拿到 None
```

> 这个接口是 **`data.rows`**，不是广告接口常见的 `data.page.rows`。

### 关键字段

| 字段 | 说明 |
|---|---|
| `id` | **产品库 id**（8 位，全局唯一）——建活动/加产品时用的就是它 |
| `asin` / `sku` / `parentAsin` / `isVariation` | 变体关系 |
| `standardPrice` / `landedPrice` | 标准价 / 到手价 |
| `mainBigImage` | 主图 |
| `dxmState` | 上架状态 |

### 三个注意

1. **必须 `defaultPageType=1`**，`=2` 只返回 `totalSize` 不带行。
2. **价格快照可能过期**。本项目 `online_products.updated_at` 停在 2026-10-05，而广告实际成交价已不同
   （排水沟目录到手价 9,543，实际成交 6,472）。**比价前先刷新售价，不要直接引用库里的价。**
3. 子体/父体是两个端点，不是换参数：
   - 子体：上面这个 `product/pageList`
   - 父体：`POST /api/parent/product/pageList.json`（`startTime`/`endTime` **必填**，空则 0 条）
   - 行内 `isVariation`：子体 = 2，父体 = 1

## 竞品抓取

竞品数据**不走赛狐接口**，走本地浏览器抓亚马逊搜索页：

```bash
python3 amazon_search_scrape.py --query "チェストリグ" --headless --scrolls 1
```

- 抓 `https://www.amazon.co.jp/s?k=<词>&language=ja_JP` 第一页
- 输出 `explore/amazon_search_<词>.json`
- 字段：`asin` `title` `price_value` `list_price` `rating_value` `review_count`
  `delivery_date` `free_shipping` `badges` `bought_recently` `sponsored` `raw_text`
- 缓存：本地文件永久 + 库 TTL 1800s；`--refresh` 强制重抓

### 反爬安全边界（务必遵守）

| 约束 | 值 |
|---|---|
| 两次真实抓取最小间隔 | 6s（+0~3s 随机抖动） |
| 并发 | **禁止**（全局锁） |
| 单次翻页 | 1~2 屏（`--scrolls 1`） |
| 每日建议上限 | ≤ 30 个词 |
| 撞验证码 | 停 5 分钟以上（`AMAZON_PREFETCH_BLOCK_BACKOFF_SEC`） |
| 账号风险 | 用匿名 headless，**不要**用登录态 Chrome 抓亚马逊 |

### 商品页指标

智能体读详情页时：只带 UA 会返 **503**，补上 `Accept-Encoding` 或 `Accept-Language` 就 200。

- 评论数只能从「文本是 `(1,234)` 的评价链接」拿，`aria-label` 里是「5つ星のうちX」会取错
- 品牌没有独立节点，从图片 alt 前缀切（`スポンサー広告 - <品牌> <标题>`）
- 高清图取 `img.s-image` 的 `srcset` 最大档（`._AC_UL960_`），别猜尺寸后缀
- 广告位 href 是 `/sspa/click?…`，`url` 一律用 `/dp/{ASIN}`

## 竞品指标口径

拿到「我方售价 + 竞品前 12 条」后按这套算：

| 指标 | 公式 | 判断阈值 |
|---|---|---|
| 价格分位 | 比我方便宜的竞品数 ÷ 样本数 | > 85% = 价格劣势明显 |
| 溢价率 | 我方价 ÷ 竞品中位价 − 1 | > 50% = 转化几乎不可能 |
| 标题相似度 | 关键 token 命中数 ÷ token 总数 | < 25% 误匹配；≥ 40% 同类 |
| 时效差 | 我方到货天数 − 竞品最快到货天数 | 越大越吃亏 |
| 竞争强度 | 前 12 名中位评论数 + 是否有 500+ 评论头部 | 决定新品能否挤进去 |

```python
import statistics as st

def compete(our_price, items):
    prices = [i["price_value"] for i in items if i.get("price_value")]
    return {
        "median": st.median(prices),
        "our_gap_pct": (our_price / st.median(prices) - 1) * 100,
        "our_percentile": sum(1 for p in prices if p < our_price) / len(prices) * 100,
        "min": min(prices), "max": max(prices),
    }
```

## 词 × SKU 相关性（自家模块，非接口）

否词前必须过相关性判定，规则在 `backend/term_relevance.py`：

- 口径：`score = 0.60×coverage + 0.25×contig + 0.15×lcs`
- 分档：≥ 0.85 高度相关 / ≥ 0.60 相关 / ≥ 0.35 弱相关 / < 0.35 不相关

> **不要用 Dice 当第二成分**——长标题会把 Dice 稀释，导致「整串就是标题子串」只拿 0.78。

> **否词硬门槛**：`点击 ≥ 10` **且** `相关性 < 0.35` 才可以否。
> 只看"0 单"就否词会砍掉最精准的流量（实测 2026-11-08 全部 21 条搜索词都是相关词，
> 其中 `チェストリグ` 就是「战术胸挂」的日文同义词）。
