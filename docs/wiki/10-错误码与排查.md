# 10 错误码与排查

---

## 错误码表

| code | 含义 | 典型原因 | 怎么办 |
|---|---|---|---|
| `0` | 请求被受理 | **不代表全部成功** | 检查行内 `code` / `errMsgList` / `data` |
| `-1` | 参数错误 / 对象不存在 | id 类型传错（内部 id ↔ Amazon id） | 对照 [双 id 体系](01-快速开始.md#双-id-体系最容易错的地方) |
| `2001` | 登录态失效 | Cookie 过期 | 重新从浏览器取 Cookie，不要高频重登 |
| `360000` | 参数校验失败 | **编码用错**（JSON 传了 form 接口）、数组传成字符串、必填缺字段 | 先查编码，再查字段类型 |
| `360000` | 同上 | 例：`updatePortFolioData` 少传 `policy`/`amount` | 补齐字段 |
| `500` | 系统异常 | 老接口参数结构不对 | 换新旧两套路径试 |
| `404` | 路径不存在 / 未灰度 | gw 灰度路径没开 | 换老路径 |
| `429` | 平台限流 | 请求太密 | 降频，间隔 ≥ 2s |

---

## 排查顺序（照着走，别乱猜）

```
1. 编码对不对？
   JSON 接口用 form 提交 → 360000
   form 接口用 JSON 提交 → 360000
   ↓ 对
2. id 类型对不对？
   写操作要用"内部 id"，不是 Amazon id
   读列表要用"Amazon id"，不是内部 id
   ↓ 对
3. 根 code=0 吗？
   不是 → 看 msg
   ↓ 是
4. 子响应呢？
   campaignResp.code / groupResp.code / targetResp.code
   errMsgList 非空？
   data 是字符串化的 JSON 数组吗？
   ↓ 都对
5. 读回确认真的生效了吗？
   多数写接口不回传新值，必须再查列表
```

## 三个最易误判的场景

### ① `code:0` 但实际没成功

| 接口 | 错误藏在哪 |
|---|---|
| `ad/sp/create` | `data.campaignResp.code` / `groupResp.code` / `targetResp.code` |
| `product/v2/add.json` | `data` 是**字符串化 JSON 数组**，非空即部分失败 |
| `negative/createSpGroupNeKeywords` | `data.errMsgList` 非空 |
| `multiple/target/getAllTargetData` | `targetList[].code` |
| `movePortFolioData` | `data[].errMsg` |

### ② 过滤参数不生效

`statusList` / `portfolioIdList` / `adType` 传了也不严格生效，返回可能是全量。

→ **拉全量后按行字段本地二次过滤**，不要依赖服务端过滤。

### ③ 返回 200 但数据为空

常见原因：

| 现象 | 原因 |
|---|---|
| 列表 0 行 | `startDate`/`endDate` 为空（部分接口必填，如 target/group/placement） |
| ABA `data: []` | 少了 `departmentNames`，或词本身无 ABA 记录 |
| 在线产品 0 行 | 取了 `data.page.rows`（应为 `data.rows`） |
| 投放 0 行 | `campaignIdList` 传了内部 id，或 `targetType` 没设成 `auto` |
| 关键词建议空 | 没先加广告产品（ASIN） |

## 各接口的必填"陷阱字段"

| 接口 | 必须要给 | 不给会怎样 |
|---|---|---|
| `multiple/target/getAllTargetData` | `startDate` / `endDate` | `360000 开始日期不能为空` |
| `multiple/group/getAllGroupData` | 同上 | 同上 |
| `multiple/placement/getAllPlacementData` | 同上 | 同上 |
| `search/terms/analysis/getTrend.json` | `departmentNames` | 返回空数组 |
| `adKeyword/sp/suggestKeywordsByAsin/page` | `asinList`（不是 `asins`） | `asinList: must not be null` |
| `spTarget/getSuggestedBid` | `targetIds` 逗号字符串 + Amazon targetId | `160000` / 对象不存在 |
| `parent/product/pageList.json` | `startTime` / `endTime` | 0 条 |
| `product/pageList` | 完整 BASE 参数 + `defaultPageType=1` | 0 条 / 只有 totalSize |

## 自检清单（跑完一轮取数后核对）

- [ ] 活动级 `impressions` / `clicks` / `adCost` 与赛狐后台一致
- [ ] 组级求和 ≈ 活动级（差异应在个位数）
- [ ] 投放 4 个匹配位求和 ≈ 活动级
- [ ] 搜索词 + 搜索 ASIN 的花费覆盖 ≥ 85% 总花费
- [ ] ABA 排名抽查 1 个词，与页面显示一致
- [ ] 我方售价与 Amazon 前台一致（注意快照可能过期）
- [ ] 竞品抓取 `item_count` ≥ 12 且 `blocked=false`
